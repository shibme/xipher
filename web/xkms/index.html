Xipher KMS (XKMS)

A self-hosted credential provider for Xipher: OIDC-authenticated, deterministic key derivation, no key storage.

XKMS derives Xipher secret keys from verified OIDC identities with HKDF-SHA256 and serves entity public keys over an unauthenticated /xpk/ tree. It is a custodial model — the master seed can derive any identity's key — so deploy it only where that trust is acceptable.

Run it

helm repo add xipher https://xipher.org/charts
helm install xkms xipher/xkms

Or run the built-in hidden subcommand: xipher kms --config /path/to/xkms.yaml.
