# Xipher

> Key/password-based asymmetric encryption with optional post-quantum security. CLI, browser app (WebAssembly), Go library, and GitHub Action.

This is the Markdown entry point for the Xipher web app page.

The documentation is one canonical file: **https://xipher.org/docs.md**.

- [Web app guide](https://xipher.org/docs.md#web-overview): what the app does, where keys live, offline/PWA behavior.
- [Keys & passwords](https://xipher.org/docs.md#web-keys): password, secret key, and random identities.
- [Passkeys](https://xipher.org/docs.md#web-passkeys): WebAuthn PRF → HKDF-SHA-256 → 64-byte seed.
- [Post-quantum encryption](https://xipher.org/docs.md#post-quantum): X25519 + ML-KEM-1024 hybrid.
- [Encrypting files](https://xipher.org/docs.md#web-files): streaming encryption to `.xipher` files.
- [Full documentation](https://xipher.org/docs.md): CLI, library, XKMS, architecture.
- [Agent index](https://xipher.org/llms.txt): everything in one place.
